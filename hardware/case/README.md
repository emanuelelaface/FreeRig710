# FreeRig710 ESP32-P4 case

This directory contains the two STL files supplied for the FreeRig710 ESP32-P4 hardware:

- `top.stl`
- `bottom.stl`

Measured STL bounding boxes (millimetres):

- top: approximately **55 × 55 × 26.1 mm**
- bottom: approximately **55 × 55 × 5.6 mm**

Both supplied meshes are watertight.

## Suggested print starting point

These are general slicer suggestions, not a validated material/profile requirement:

- units: millimetres;
- layer height: 0.20 mm;
- 3 perimeters/walls;
- 15–25% infill;
- PLA or PETG;
- orient the largest flat face toward the build plate and inspect bridges/overhangs in the slicer before printing.

Check connector clearances against your exact Waveshare board, CSI cable and HDMI-to-CSI adapter before committing to a long print, because component/cable revisions can vary.
